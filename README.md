# Zen Crest Realty

Marketing site for Zen Crest Realty, a real estate firm in Bengaluru, India.

Built with Astro and Tailwind CSS. Deployed to Cloudflare Pages.

## Requirements

Node.js 22.12.0 or newer.

## Install

```sh
npm install
```

## Run the dev server

```sh
npm run dev
```

The site is served at http://localhost:4321.

## Build

```sh
npm run build
```

The production build is written to `dist/`. Preview it locally with:

```sh
npm run preview
```

## Editing site copy

**All site copy and data live in `src/data/content.json`.** Text is never
hardcoded in `.astro` files — to change wording, headings, service names,
contact details or any other content, edit `content.json` and rebuild.
